**BetGo – Property Rental and Sales Platform**

BetGo is a property marketplace built with Laravel that allows users to find apartments, houses, offices, and other properties for rent or sale in Addis Ababa, Ethiopia.

Users can search and filter properties by location, price, property type, and number of bedrooms. They can save their favorite listings and contact property owners or agents through the built-in messaging system.

Property owners and agents can register, submit their information for approval, create property listings, upload photos, and manage their listings through a dashboard. Administrators can review listings, manage users, monitor payments, and track platform activity.

The platform supports Chapa for local payments and Stripe for international card payments. It also includes paid listing plans, real-time notifications, an interactive map, and an admin dashboard with analytics.

**Technologies:** Laravel, PHP, Blade, Alpine.js, Tailwind CSS, MySQL, Stripe, Chapa, Laravel Echo, and Leaflet.
